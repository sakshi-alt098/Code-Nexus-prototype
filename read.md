## Frontend Repository Branch: `frontend-only`

### Key Modules:
1. **Starting Video Animation**: Cinematic hero splash with smooth transition into the platform.
2. **Enterprise Role-Based Auth**: Independent login portals and strictly segregated dashboards for Creator, Manager, Authorised Reviewer, and Admin.
3. **Pre-Flight Diagnostic Studio**: Deterministic + AI rule checking with 1-click fixes and intent preservation.
4. **Visual & WCAG 2.1 Contrast Checker**: Official 5-color palette matcher and accessibility calculator.
5. **Review & Approval Hub**: Side-by-side diff viewer, reviewer comments, and tamper-proof audit history.
6. **Governance Insights**: Repeated mistakes metrics and ambiguous guideline discovery.

### How to Run:
```bash
cd frontend
npm install
npm run dev
```
Open: `http://localhost:5173`
